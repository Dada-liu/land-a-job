## Blast radius

- [ ] **Database**: new column / new migration → sync `tables.ts`, the core schema, and the `user_version` assertion in `schema.test.ts`; state the default for historical rows after an old database upgrades
- [ ] **MCP tools**: added/removed → sync `TOOL_MANIFEST`, `manifest.test.ts`, `ARCHITECTURE.md` §7.2 and every documented tool count
- [ ] **Skills**: added/removed or version bump → sync `SKILL_REGISTRY`, `SKILL.md` frontmatter, documented skill count; say whether `scripts/install-skills.sh` must be rerun and the agent restarted
- [ ] **API**: new / changed paths → sync the "Local API" table in `README.md` and §6.2 in `ARCHITECTURE.md`
- [ ] **Web**: new page / route / displayed field → say whether it involves `lazy()` loading and `data-testid` (E2E depends on it)
